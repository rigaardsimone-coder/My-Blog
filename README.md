# My Blog

A cozy and aesthetic blog website built with HTML, CSS, and JavaScript.

## Features

- Create and save blog posts with title, category, date, location, and tags.
- Rich text editor for bold, italics, headings, lists, colors, highlights, and fonts.
- Upload images and attachments such as documents or PDFs.
- Add comments to posts.
- Customize the site banner, logo, and background images.
- Save quick notes locally.

## Usage

1. Open `index.html` in a browser.
2. Click **New Post** to create a new blog entry.
3. Customize the page via the **Customize** button.
4. Use the editor toolbar or right-click inside the editor for styling options.

## Files

- `index.html` — main page structure.
- `styles.css` — cute pastel design and layout.
- `app.js` — blog logic, local storage, rich text editor, and file uploads.
